# WAHM SHERLOCK V70 — Golden Lens Edition

أقوى محرك بحث عكسي بالصور في العالم العربي. تقنية التعرف على الوجوه بالذكاء الاصطناعي.

## 🚀 المميزات

- ✅ **بحث عكسي حقيقي** عبر Google Images باستخدام Puppeteer
- ✅ **تصميم ذهبي فاخر** مع وضع ليل/نهار
- ✅ **واجهة سلسة** مع رسوم متحركة احترافية
- ✅ **دعم العربية** كاملاً
- ✅ **رفع الصور** بسحب وإفلات أو لصق من الحافظة
- ✅ **فلاتر النتائج** حسب المنصة والتطابق
- ✅ **مجاني 100%** بدون API خارجي مدفوع

## 📋 المتطلبات

- Node.js >= 18.0.0
- npm أو yarn

## 🔧 التثبيت

```bash
# استنساخ المشروع
git clone <repository-url>
cd wahm-sherlock-node

# تثبيت المكتبات
npm install

# بدء الخادم
npm start

# أو للتطوير مع المراقبة
npm run dev
```

الخادم سيعمل على `http://localhost:3000`

## 🔍 كيفية الاستخدام

1. **رفع الصورة:**
   - اسحب الصورة إلى منطقة الرفع
   - أو انقر للاختيار من الملفات
   - أو الصق من الحافظة

2. **بدء البحث:**
   - انقر على "بدء المسح"
   - سيبدأ البحث العكسي الحقيقي

3. **عرض النتائج:**
   - سيتم عرض جميع الصور المطابقة
   - يمكنك فلترة حسب المنصة
   - انقر على "عرض" للذهاب للمصدر

## 🌐 النشر على Render

### خطوات النشر:

1. **إنشاء حساب على Render:**
   - اذهب إلى [render.com](https://render.com)
   - سجل دخول أو أنشئ حساب

2. **ربط مستودع GitHub:**
   - ادفع المشروع إلى GitHub
   - اتصل مستودعك بـ Render

3. **إنشاء خدمة جديدة:**
   - اختر "New +" → "Web Service"
   - اختر المستودع
   - اترك الإعدادات الافتراضية
   - انقر "Create Web Service"

### متطلبات Render:

- **Build Command:** `npm install`
- **Start Command:** `npm start`
- **Node Version:** 18+

### ملف Render.yaml (اختياري):

```yaml
services:
  - type: web
    name: wahm-sherlock
    env: node
    buildCommand: npm install
    startCommand: npm start
    envVars:
      - key: NODE_ENV
        value: production
      - key: PORT
        value: 3000
```

## 🛠️ المكتبات المستخدمة

- **Express.js** - خادم الويب
- **Puppeteer** - أتمتة المتصفح والبحث
- **Multer** - معالجة رفع الملفات
- **CORS** - السماح بطلبات متعددة الأصول
- **Sharp** - معالجة الصور
- **Axios** - طلبات HTTP
